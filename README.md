# Mini RPG Demo

Pequeña demo inspirada en los clásicos Zelda de Game Boy.

## Requisitos

- Python 3.11
- pygame 2.6

Instala las dependencias:

```bash
pip install -r requirements.txt
```

## Ejecutar

```bash
python main.py
```

Para ejecutar en modo sin pantalla (por ejemplo en pruebas automáticas):

```bash
SDL_VIDEODRIVER=dummy python main.py --frames 10
```
